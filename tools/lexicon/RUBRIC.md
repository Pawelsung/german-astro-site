# 主字庫分級規則

給負責分級的人或代理（agent）看。每一批輸入是 `batches/batch-NN.tsv`，輸出寫到 `tags/batch-NN.tsv`，然後執行 `node tools/lexicon/check-tags.mjs` 檢查。

## 輸出格式

TSV，第一行是標題，之後每個輸入詞條一行，順序和輸入相同，不可增減：

```
id	level	topic	kind	push	flag
```

| 欄位 | 允許值 | 說明 |
| --- | --- | --- |
| `id` | 照抄輸入 | |
| `level` | `A1` `A2` `B1` `B2` `C1` | 一般德語學習者「應該在這個程度學會」的等級，參考歌德／ÖSD 考試字表的常見分法與使用頻率。片語取整個用法的程度，不是最難那個字的程度 |
| `topic` | 見下方主題表的代號 | 只選一個最主要的 |
| `kind` | `word` `phrase` `term` `chunk` | `phrase`：固定搭配或句型（sich freuen auf、eine Prüfung bestehen）；`term`：文法或上課用的術語（Akkusativ、Nebensatz）；`chunk`：筆記裡的片段或具體數字時間（ab 8 Uhr、2. OG、alle drei Jahre） |
| `push` | `y` `n` | 是否適合當每日一字或推播。`term`、`chunk` 一律 `n`；專有名詞、太罕見或釋義有問題的也填 `n` |
| `flag` | 空白或簡短中文 | 有疑慮才寫：冠詞或詞性可能錯、釋義有誤、應該併到別的詞條、程度拿不準（寫「程度？A2/B1」） |

## 主題代號

| 代號 | 主題 | 代號 | 主題 |
| --- | --- | --- | --- |
| `daily` | 日常生活、作息 | `work` | 工作、職場、商務 |
| `food` | 飲食、餐廳 | `school` | 學校、學習、語言 |
| `shop` | 購物、金錢 | `health` | 身體、健康、醫療 |
| `home` | 居家、住房、家具 | `people` | 家庭、人際、外表個性 |
| `travel` | 交通、旅行、方向 | `feel` | 情緒、感受、態度 |
| `city` | 城市、地點、機構 | `leisure` | 休閒、運動、娛樂 |
| `nature` | 天氣、季節、自然、動物 | `media` | 媒體、科技、通訊 |
| `time` | 時間、日期、數量 | `society` | 社會、政治、環境、文化 |
| `grammar` | 功能詞與文法（介系詞、連接詞、代名詞、助動詞、術語） | `general` | 抽象通用、無法歸類 |

## 判斷原則

- 先看德文本身的常用程度，再看中文釋義確認意思；同一個字多種意思時，用最常見的意思分級。
- 常見基礎動詞、代名詞、介系詞、數字、家庭成員、食物等 → A1。
- 寫信、約時間、描述過去、旅行問題處理等日常延伸 → A2。
- 表達意見、工作職場、媒體、情緒細節、抽象名詞（-ung、-heit 等常見者）→ B1。
- 較正式、書面、專業或少見的詞 → B2；明顯更高才用 C1。
- 不要因為字長或是複合字就自動提高程度。
