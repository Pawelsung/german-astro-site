# 第 1 階段：統一複習（2026-11-09 使用者已確認）

## 目標

每天打開網站，一個畫面只做一件事：看字、點一下看意思、自己判斷。複習紀錄全站一份，舊進度完整保留。

使用感參考 Daily Deutsch 的互動方式與節奏（低密度、大字、翻卡而非考試、底部滑出字卡、每天一小份），不照抄名稱、標誌、版面與配色；冠詞顏色是這個網站自己的識別。

範圍：先做「今天」首頁和 `/review`，第 1～7 課的畫面維持原樣。

## 已確認的決定

| 項目 | 決定 |
| --- | --- |
| 每日字數 | 使用者自訂，預設 15。達到目標就算完成，但可以繼續做，沒有上限 |
| 每日佇列 | 到期字優先（最多 N − 3）；70／20／10 只分配剩下的名額；積壓超過 2N 暫停新字 |
| 評分 | 會了：升一箱。不會：回第 1 箱，明天到期，本輪再出現一次。有點印象：箱號不變，間隔減半且至少 1 天，不算錯 |
| 箱與間隔 | 第 0～5 箱為 0、1、3、7、16、35 天；所有字加第 6 箱，60～90 天 |
| 狀態 | 第 0～1 箱學習中，第 2～3 箱快會了，第 4 箱以上已學會 |
| 一鍵標記的 A1–A2 | 不排固定回訪，只靠 10% 名額和每週抽考 10 字；答錯回學習中 |
| 冠詞 | 正面只顯示名詞，翻面看冠詞，「冠詞沒想對」按鈕只記冠詞錯誤，不降箱 |
| 程度檢測 | 約 40 個 A2 字，認識 32 個以上才詢問是否整批標記；不認識的字進學習中 |
| 舊紀錄 | 最高換算到第 3 箱（快會了） |
| 內容抽查 | 做 `/review` 之前要完成抽查和出題池內的標註 |
| 音檔 | 同意產生，先 dry-run |
| 第 2～7 課 | 留到下一階段 |

## 資料

- 紀錄 key：`gw-review-v1`，雲端文件 `users/{uid}/learning/review`。
- 紀錄編碼成字串（`words`、`stars`），不用 Firestore 巢狀 map：3012 字 × 8 欄 × 2 個自動索引會超過每份文件 40,000 筆索引項目的上限。
- 瀏覽器只載入 `src/data/lexicon/site/`（`index.json`、各程度檔、`lists.json`），`lexicon.graded.json` 不進 bundle。首頁不載入字庫。
- 詞條 id 由 `src/data/lexicon/ids.lock` 鎖定，只增不減；合併過的 id 記在 `redirects.json`。

## 第 1 課進度遷移

- 兩份來源都要讀：`deutschLernkartenDB_vPro` 和 `german-vocabulary-library-v1`。
- 對應順序：`冠詞|字` 完全相符，再查 `variants`。
- 舊狀態換算：`errors > 0` → 第 1 箱今天到期；答對 1～2 次 → 第 2 箱；答對 3 次以上 → 第 3 箱；只翻過卡 → 第 0 箱；只有收藏 → 只進收藏；從未練習 → 不建立紀錄。
- 只補尚無紀錄的 id，可重複執行；寫入後要讀回驗證；舊 key 全部保留。
- 無法對應的紀錄留在原處，第 1 課照常可練，設定頁顯示筆數。

## 同步

只寫內容有變的文件；複習紀錄同步延遲 5 秒，結束時立刻送出；同一分頁 10 分鐘內不重複下載。合併：每字以 `t` 較新者為準，同時間取較低箱號；計數取最大值；收藏每字以時間為準；設定整包以 `t` 為準。
